## Objective

Build and maintain a multi-VM home lab environment to support hands-on security practice across SIEM, monitoring, forensics, and penetration testing disciplines.

## What I Built

- Provisioned and maintained multiple VMs running Ubuntu/Debian, configured with host-only and NAT networking to simulate isolated and internet-connected network segments
- Used the lab as the foundation for the ELK Stack, rsyslog centralized logging, LibreNMS/SNMP monitoring, and penetration testing projects documented in this portfolio
- Managed VM snapshots to enable safe rollback after destructive testing (exploit exercises, configuration changes)
- Maintained documentation of configurations, issues encountered, and resolutions — treating the lab like a production environment

## Skills Demonstrated

Linux system administration · VirtualBox VM management · Network segmentation (host-only / NAT) · Snapshot and rollback management · Lab documentation · Infrastructure-as-practice methodology
